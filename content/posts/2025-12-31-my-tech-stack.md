I thought it'd be fun to write about the tech stack I used in 2025 and see how things change throughout the years. For the most part, I try to have fewer tools and gadgets with notifications turned off. This helps me stay focused during work and fully disconnect when I'm not.

## Hardware

- iPhone 16 Pro (2025)
- MacBook Pro 14-inch (2023) with Apple M2 Pro CPU

The MacBook is a couple of years old now, but still going strong. With how fast the new Apple chipsets are, I don't foresee upgrading anytime soon.

I did upgrade my phone earlier this year from an iPhone 11, so it was a big jump (in both performance and screen size). Not that I really use my phone all that much, the main draw for me was the amazing camera.

## Software

- IDE: [Zed](https://zed.dev/)
- Terminal: [Ghostty](https://ghostty.org/)
- Notebook: [Positron](https://positron.posit.co)
- Editor: [Sublime Text](https://www.sublimetext.com/)

I started using Zed once they open-sourced it back in 2024, and it's been my main IDE since then. I really like its design and speed. The only times I use a different IDE is when I'm working with notebooks (Python and R), in which case I use Positron (which is a fork of VS Code).

Back in January, I began using Ghostty and dropped iTerm soon after. It's super fast and has great defaults.

And of course, Sublime Text is my favorite editor. My favorite feature is that it preserves unsaved files on quit. I mainly use it for note-taking, editing random files, or as a scratch pad.

## Miscellaneous

- LLM Agent: [Claude](https://claude.ai/)
- Fonts: [Berkeley Mono](https://usgraphics.com/products/berkeley-mono)
- Theme: [Atom One Dark](https://github.com/atom/atom/tree/master/packages/one-dark-syntax)
- Password Manager: [1Password](https://1password.com/)

Claude has been my default LLM this past year. My favorite way of using it is for learning and understanding new concepts, or for brainstorming ideas and implementation plans. My side projects have been seeing a lot of love lately with Claude Code as well. It's amazing to see the advancements in AI over the past couple of years.

I use the Berkeley Mono font and the One Dark theme in my coding programs. Nothing much to say about that, but I wanted to mention them to see how my preferences change over time.

Lastly, I'd like to mention 1Password since I use it a lot, not just for storing passwords (with [email masking](https://support.1password.com/fastmail/)), but also SSH, API, and license keys.
